02

Install or update

  1. Extract the downloaded ZIP into a permanent folder.
  2. Open chrome://extensions and turn on Developer mode.
  3. Choose Load unpacked and select that folder.
  4. For later updates, replace the folder contents and click Reload.

03

Report what happened

One report gives us the import summary. Separate issue entries help us fix each individual miss.

Reporting not yet open

Reports are kept out of the public repository.

What to include

  • A screenshot of the final import summary
  • Your class, subclass, and relevant levels
  • Anything unusual that did not make it through
  • How seriously each miss affected the character
  • An optional screen name if follow-up is okay

You may attach a file instead and let us work through it on our side.

What happens after you start

Once the import begins, you do not need to sit and watch it unless you want to. You can use another browser tab while it continues in the background.

Issues are handled by impact and urgency rather than strictly by submission time.

Your privacy

This public page does not collect names, analytics, character data, or browser activity.

Never include passwords, account recovery information, private messages, or anything you do not want the testing team to review.

Updates

You will know when a newer build is ready.

The installed tool will compare its version with this page’s current-version notice. When a newer build is available, it will point you back here for the update.
